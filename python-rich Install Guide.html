Python · Linux · macOS · Windows

About

Rich prints color, tables, progress bars and Markdown in the terminal. Here is how to install it on Linux, macOS and Windows.

Systems

Arch Linux

Rich is in the official extra repository as python-rich. The same command works on EndeavourOS and CachyOS.

sudo pacman -S python-rich

python-rich

Package page ↗

Debian and Ubuntu

Rich is packaged as python3-rich. The same command works on Linux Mint and other Debian-based systems.

sudo apt install python3-rich

python3-rich

Package page ↗

Fedora

Rich is packaged as python3-rich, built from the source package python-rich.

sudo dnf install python3-rich

python3-rich

Package page ↗

Other Linux

If your distribution has no package, or the package is old, use pip inside a virtual environment.

python3 -m pip install rich

macOS

Use Python from python.org or Homebrew, then run pip inside a virtual environment.

python3 -m pip install rich

Windows

Virtual environment

Linux and macOS

$ python3 -m venv .venv
$ source .venv/bin/activate
$ pip install rich

Windows

> py -m venv .venv
> .venv\Scripts\python.exe -m pip install rich
> .venv\Scripts\python.exe your_script.py

Arch, Debian 12 and newer, Ubuntu 23.04 and newer and Homebrew mark their Python as externally managed (PEP 668). A plain pip install there fails with externally-managed-environment. Create a virtual environment for your project and install rich inside it.

Packages from pacman, apt and dnf live in the system Python. A virtual environment does not see them unless you create it with --system-site-packages.

Python package managers

Tool Command Use it
pip python3 -m pip install rich In an activated virtual environment

Poetry poetry add rich In a Poetry project
conda conda install -c conda-forge rich In a conda environment

Check the install

$ python3 -m rich

This prints a demo of colors, tables and syntax highlighting. On Windows use py -m rich. Inside a virtual environment, run it with that environment's Python.

from rich import print
print("[bold green]Rich works[/bold green]")
